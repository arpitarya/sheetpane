# Starters

Each `create-sheetpane` template, scaffolded by the CLI (`scripts/build-starters.mjs`, `just starters`) —
the same files `npm create sheetpane@latest -- --template <name>` writes. Generated: do not edit by hand.

| template | folder | try it |
|---|---|---|
| Vanilla — Vite + TypeScript, no framework | [`vanilla/`](vanilla/) | [Open in StackBlitz](https://stackblitz.com/github/arpitarya/sheetpane/tree/v0.1.0/examples/starters/vanilla) |
| React 19 — Vite | [`react/`](react/) | [Open in StackBlitz](https://stackblitz.com/github/arpitarya/sheetpane/tree/v0.1.0/examples/starters/react) |
| Next.js — App Router, the sheet on the client only | [`next/`](next/) | [Open in StackBlitz](https://stackblitz.com/github/arpitarya/sheetpane/tree/v0.1.0/examples/starters/next) |
| Vue 3 — Vite | [`vue/`](vue/) | [Open in StackBlitz](https://stackblitz.com/github/arpitarya/sheetpane/tree/v0.1.0/examples/starters/vue) |
| Angular — a standalone component | [`angular/`](angular/) | [Open in StackBlitz](https://stackblitz.com/github/arpitarya/sheetpane/tree/v0.1.0/examples/starters/angular) |
| Svelte 5 — Vite | [`svelte/`](svelte/) | [Open in StackBlitz](https://stackblitz.com/github/arpitarya/sheetpane/tree/v0.1.0/examples/starters/svelte) |

The links open this folder at `v0.1.0`; StackBlitz installs `@sheetpane/*` 0.1.0 from npm, so a starter runs
once that version is published. Locally: `npm create sheetpane@latest` (SR-CREATE).
