Board 8 · @sheetpane/charts · Edit mode · two stages

Charts — first show where a chart sits and what it reads; draw it later

Stage 1 ships a frame at the chart's anchor with its title and type. “Show source cells” selects what the chart reads. After the reviewer changed H12, the frame says Excel will redraw it — sheetpane never edits a chart.

View differs only in the chip: nothing is edited in View, so “data changed” never shows. “Show source cells” works in both modes.

Stage 2 rules
  • Bar, column (clustered and stacked), line, pie and scatter (W-21); every other type stays a stage-1 frame.
  • Accent bars; a negative value is red and sits left of the zero line — the label says −9,180 too.
  • No authoring: no type switcher, no series editor, no resize. The frame is the chart's anchor.
  • Draws from the cached series values; with formulas installed, from the live cells — so H12 already reads 52,338.
