Two components you place anywhere — linked behind the scenes.

SheetPaneExcel shows the file and lets people flag a cell. SheetPaneErrors lists what was flagged and holds the form. Put them in the same tab, different tabs, or a pop-up. They always share one pane, so they act as one.

1<SheetPaneExcel>

The sheet. View or Edit. Cells as plain text, merged and centred cells, sheet tabs, find, zoom. In Edit, typed values stay in memory and Export writes the latest values.

Alone in Edit: the error form opens next to the cell.

Install and place them — React 
import { useSheetPane, SheetPaneExcel, SheetPaneErrors } from 'sheetpane';
import 'sheetpane/style.css';

const pane = useSheetPane({ src: file, errors: saved });

// Anywhere in your layout — same pane, so they're linked
<Tab title="Holdings file">
  <SheetPaneExcel pane={pane} mode="edit" height={640} />
</Tab>
<aside>
  <SheetPaneErrors pane={pane} onReveal={() => setTab('file')} />
</aside>

pane.on('errors', saveDraft);   // every add, edit, resolve, delete
pane.export();                  // .xlsx or .csv with the latest values in memory

// The sheet also works on its own (View, or Edit with its own form)
<SheetPaneExcel src={file} display="popup" open onClose={close} />

// Web components link by id
<sheetpane-excel pane="q3" src="/files/holdings.xlsx"></sheetpane-excel>
<sheetpane-errors pane="q3"></sheetpane-errors>

<SheetPaneExcel> props
paneLink to a SheetPaneErrors. Optional.
src.xlsx or .csv — only when used without a pane.
mode · modes"view" | "edit"; modes hides Edit for read-only users.
display · open · onClose"tab" or "popup".
heightTab only.
allowCellChangesLet Edit change cell values (kept in memory).
onExportExport button — .xlsx/.csv with the latest values.
<SheetPaneErrors> props
paneRequired — the same pane as its SheetPaneExcel.
errorTypesYour catalog; defaults to seven types.
readOnlyList only: no form, no resolve (sign-off view).
onReveal“Show in sheet” — switch tab or open the pop-up.
Edits stay in memory

Every typed value lives in the pane; Export writes the latest values.

Order doesn't matter

Mount either first; they find each other through the pane.
