Host responsibility · outside the component

Your app decides which plugins are installed. Here: none, so the grid is exactly today's.

import 'sheetpane';                       // defines <sheetpane-excel>, <sheetpane-errors>
const sheet = document.querySelector('sheetpane-excel');
sheet.plugins = [];                       // nothing installed → no format row, no extra controls
Rules every plugin board keeps
  • Add only inside a named slot. Never move, hide or restyle a core part.
  • “Flag issue” stays first in the selection bar; plugin buttons come after the core ones.
  • No font family anywhere — text inherits the host font. Size and weight only inside the styles row.
  • Colour never alone: changed = corner mark, flagged = numbered pin, derived = ⟳, stale = “may be stale”.
  • Toolbar 36 px · format row 32 px · cells 28 px at 100 %. --sp-* tokens only, light and dark.
  • Core grows too, outside the slots: Undo · Redo (W-23) and Freeze ▾ (W-24) join the toolbar in Edit. This board is the grid before them; every other board shows them.
