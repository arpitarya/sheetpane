# W-32 — Plugin tabs in both demos: vanilla, one per plugin, all plugins

## At a glance

| step | what we do | what it gives us | state |
|---|---|---|---|
| 1 | Build one showcase workbook with a sheet per feature (number formats, styles, formulas, validation, conditional formats, a picture, a chart, comments) | the same file in every tab, so the difference is the plugin and nothing else | ✅ |
| 2 | Add a tab row to the HTML demo: **Vanilla** · numfmt · styles · formulas · validation · condfmt · images · charts · comments · **All plugins** | see each plugin's effect side by side, no framework | ✅ |
| 3 | The same ten tabs in the React demo | the same, the way a React host wires it | ✅ |
| 4 | Extend `demo-check` to open every tab and assert its plugin's mark is there (and absent in Vanilla) | the gallery can't silently break | ✅ |

**Arpit, 2026-10-18:** *"For demo items, I want HTML and React to have multiple tabs with vanilla grid, with different different plugins, how the grid is going to look like, and with all plugins, how the grid is going to look like."*

**Model:** Sonnet — wiring existing public exports into two demos plus one generated fixture; no new design or contract.

## Goal

Both demos become a plugin gallery. Ten tabs, each with its own `<sheetpane-excel>` (and its `<sheetpane-errors>`) on its **own `pane`** so tabs never sync with each other (SR-LAW-7 is per pane). Every tab loads the same showcase workbook: **Vanilla** shows what the plain grid does with it, each plugin tab shows that plugin turned on, **All plugins** shows all eight together. The existing review demo (Sheet + errors / Sheet / Errors, font, pop-up, CSV, file picker, hooks strip, column rules) keeps working. [W-33](W-33-rules-file.md) adds an eleventh tab, **Rules file**, to this gallery.

## Hazards

- **W-31 changes the toolbar** (one Download button replaces Export + Download original) and `demo-check` presses Export today. Build after W-31 lands, or rebase on it; re-derive `git status` before staging.
- **The showcase file is hand-built, not Excel-saved.** It proves the demo, not Excel compatibility — that is W-30. Say so in the generator's header comment.
- **Ten grids is heavy.** Lazy-mount (DoD 6); don't load all ten on page open.
- **Plugin registration is global** (`import '@sheetpane/numfmt'` registers it for the page); the per-element `plugins` attribute is what keeps Vanilla vanilla. Check Vanilla really renders without any plugin's effect.
- **`demo-packed`** installs from tarballs: the HTML import map and both `package.json`s must list every plugin, or the packed run fails where the workspace run passes.
